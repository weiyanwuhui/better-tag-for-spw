# Better Tag for SPW

原「歌词增强」，为 Salt Player for Windows 提供标签、封面和歌词管理。保留原插件 ID，便于从旧版升级。

安装：在创意工坊导入 Release 的 .spmod，启用并授权后完全退出并重启播放器。版本 0.6.26 包含名称调整。

本项目自有代码采用 GPL-3.0-only，第三方代码和数据保留其各自的许可与署名，详见源码资源和 [参考与致谢](REFERENCES_AND_CREDITS.md)。QRC 实现曾参考 LDDC，保守按 GPL-3.0-only 发布。
